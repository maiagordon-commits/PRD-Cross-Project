# Platform Translation Feedback – Consolidated

Single sheet consolidating localization feedback from:
- [Slack thread](https://guesty.slack.com/archives/C0BDXUK6V1R/p1782895353663379)
- French issues doc (Remi)
- Italian missing translations doc
- German HomePage corrections sheet (Patricia)

## Open as a Google Sheet

1. Download `Platform_Translation_Feedback_Consolidated.xlsx`
2. Upload to Google Drive
3. Right-click → **Open with → Google Sheets**

(Screenshots are embedded in the XLSX. Prefer XLSX over CSV for images.)

## Files

| File | Description |
