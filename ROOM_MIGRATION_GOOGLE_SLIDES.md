# Room Migration Progress → Google Slides

## Fastest path to a shareable Google Slides link

1. Download [`Room_Migration_Progress.pptx`](../Room_Migration_Progress.pptx)
2. Open [Google Drive](https://drive.google.com) (signed into your Guesty Google account)
3. Upload the `.pptx` (**New → File upload**, or drag & drop)
4. Right-click the file → **Open with → Google Slides**
5. **File → Save as Google Slides** (makes it a native Slides file)
6. **Share** → copy the link (`https://docs.google.com/presentation/d/...`)

That link is the clickable Google Slides URL you can paste into Slack, docs, etc.

## Alternative: import into an existing deck

1. Open your existing Google Slides presentation
2. **File → Import slides**
3. Upload `Room_Migration_Progress.pptx`
4. Select the slide(s) → **Import**
