## Structure
- **Summary** — team names, GitHub owners, repo & violation counts
- **All Violations** — full dataset with **Team Name** (from Owners / column B)
- **One tab per team** — Journey, Airbook, Enterprise, Unicorn, Payments, … (34 team tabs)

Owners from column B (`@guestyorg/...`) are mapped to friendly team tab names. Rows with multiple owners appear on each owning team’s tab.
