## Open as Google Slides (recommended)

1. Download `E-Invoicing_Challenges_Next_Steps.pptx`
2. Go to [Google Drive](https://drive.google.com)
3. Drag the `.pptx` file into Drive **or** click **New → File upload**
4. Right-click the uploaded file → **Open with → Google Slides**
5. Optional: **File → Save as Google Slides** so it becomes a native editable Google Slides file (not just Office compatibility mode)

After step 5 you can share a normal Google Slides link (`https://docs.google.com/presentation/d/...`).

### Alternative (from an existing Slides deck)
1. Open any Google Slides presentation
2. **File → Import slides**
3. Upload the `.pptx`
4. Select both slides → **Import**
